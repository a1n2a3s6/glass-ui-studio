# GlassUI Studio

[https://img.shields.io/badge/365%20Days%20Challenge-Day%201%2F365-blue?style=for-the-badge]
[https://img.shields.io/badge/Stack-HTML%20%7C%20Tailwind%20CSS%20%7C%20JS-06B6D4?style=for-the-badge]

An interactive **Glassmorphism CSS & Tailwind CSS generator** featuring a live animated mesh background, instant visual controls, and one-click code copying.

## Live Demo
👉 **[Try GlassUI Studio Live](https://a1n2a3s6.github.io/glass-ui-studio/)**

## Features
- **Real-Time Controls:** Adjust blur, transparency, saturation, border opacity, border radius, and glass tint.
- **5 Built-in Presets:** Switch instantly between curated glass styles.
- **Multiple Preview Modes:** Test your glass style on a Card, Modal, or Navbar layout.
- **Dual Code Export:** Copy clean Vanilla CSS or Tailwind CSS classes with one click.
- **Zero Dependencies Build:** Lightweight single-file static app.

## Built With
- HTML5
- Tailwind CSS (CDN)
- Vanilla JavaScript
